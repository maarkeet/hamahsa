# 🛒 سوبر ماركت أونلاين

موقع سوبر ماركت احترافي للطلبات عبر واتساب - بدون Backend

## ✨ المميزات

- 🛒 سلة تسوق تفاعلية متقدمة
- 🔍 بحث وترتيب ذكي في المنتجات
- 📂 تصنيفات متعددة
- 💾 حفظ البيانات محلياً (localStorage)
- 📱 إرسال الطلبات عبر واتساب
- 📱 تصميم متجاوب احترافي (Mobile First)
- 🎨 واجهة عربية جميلة مع Tailwind CSS
- ⚡ سريع وخفيف
- � لوحة إدارة منفصلة محمية بكلمة مرور
- 📊 إحصائيات المتجر
- 📤 تصدير واستيراد البيانات

## 📁 هيكل المجلدات

```
project/
├── index.html          # الصفحة الرئيسية (المتجر)
├── admin.html          # صفحة إدارة المتجر
├── README.md           # هذا الملف
├── logo.png            # لوجو المحل
└── products/           # مجلد صور المنتجات (اختياري)
```

## 🚀 كيفية الاستخدام

### 1. تشغيل الموقع

افتح ملف `index.html` مباشرة في المتصفح، أو استخدم Live Server في VS Code.

### 2. تعديل بيانات المحل

افتح ملف `index.html` وعدل البيانات التالية في السطر 314:

```javascript
const STORE_CONFIG = {
    name: "سوبر ماركت السعادة",     // غير اسم المحل
    whatsapp: "201000000000",        // رقم الواتساب (مع كود الدولة)
    deliveryFee: 15                  // رسوم التوصيل
};
```

### 3. إدارة المنتجات

افتح صفحة `admin.html`:
- كلمة المرور الافتراضية: `admin123`
- يمكنك تغيير كلمة المرور في السطر 314 من ملف `admin.html`

**مميزات لوحة الإدارة:**
- ➕ إضافة منتجات جديدة
- ✏️ تعديل المنتجات الموجودة
- 🗑️ حذف المنتجات
- 🔍 بحث وتصفية المنتجات
- 📊 إحصائيات المتجر
- 📤 تصدير البيانات (JSON)
- 📥 استيراد البيانات
- 🔄 استرجاع المنتجات الافتراضية

### 4. البيانات تتشارك تلقائياً

جميع التغييرات في لوحة الإدارة تظهر فوراً في المتجر والعكس، لأن البيانات محفوظة في `localStorage`.

## 🌐 الاستضافة

يمكنك استضافة الموقع مجاناً على:
- **GitHub Pages** (موصى به)
- **Netlify**
- **Vercel**
- أي استضافة تدعم HTML/CSS/JS

### على GitHub Pages:

1. أنشئ repository جديد على GitHub
2. ارفع الملفات (`index.html`, `admin.html`, `README.md`)
3. Settings → Pages → Source: main branch
4. احصل على رابط موقعك مجاناً!

**ملاحظة:** كلا الصفحتين ستعملان على نفس النطاق.

## 📲 QR Code

لإنشاء QR Code لموقعك:
1. استخدم موقع مثل [QR Code Generator](https://www.qrcode-generator.com/)
2. أدخل رابط موقعك (مثال: `https://yourstore.github.io/`)
3. حمل الـ QR Code وضعه في محلتك

## 🛠️ التخصيص

### تغيير الألوان

في ملف `index.html` و `admin.html`، عدل تكوين Tailwind:

```javascript
tailwind.config = {
    theme: {
        extend: {
            colors: {
                brand: {
                    500: '#22c55e',  // اللون الرئيسي (أخضر)
                    600: '#16a34a',
                    700: '#15803d',
                },
                accent: {
                    500: '#f59e0b',  // لون التمييز (برتقالي)
                    600: '#d97706',
                }
            }
        }
    }
}
```

### تغيير الأقسام

عدل مصفوفة `DEFAULT_CATEGORIES` في كلا الملفين:

```javascript
const DEFAULT_CATEGORIES = [
    { id: 'all', name: 'الكل', icon: 'fa-border-all' },
    { id: 'dairy', name: 'ألبان وأجبان', icon: 'fa-cow' },
    // أضف المزيد حسب احتياجك
];
```

## 🔒 الأمان

- الموقع آمن 100% - لا يوجد معالجة بيانات حساسة
- لا يوجد Backend أو قاعدة بيانات
- البيانات تذهب مباشرة لواتسابك
- لوحة الإدارة محمية بكلمة مرور
- البيانات محفوظة محلياً في المتصفح

## 💡 نصائح

1. **كلمة المرور:** غير كلمة المرور الافتراضية فوراً في `admin.html`
2. **الصور:** استخدم روابط صور حقيقية للمنتجات
3. **واتساب:** تأكد من رقم الواتساب صحيح مع كود الدولة
4. **النسخ الاحتياطي:** استخدم ميزة تصدير البيانات بشكل دوري
5. **الاختبار:** اختبر الموقع قبل نشره

## 📞 الدعم

إذا واجهت أي مشاكل، تأكد من:
- أن جميع الملفات في نفس المجلد
- أن المتصفح يدعم localStorage
- أن رقم الواتساب مع كود الدولة (مثال: 201234567890)
- أن كلمة المرور صحيحة للوصول للإدارة

## 🔄 النسخ الاحتياطي

من لوحة الإدارة:
1. اضغط على "تصدير البيانات" لحفظ نسخة من المنتجات
2. يمكنك استعادة البيانات عبر "استيراد البيانات"
